# Prova 07 P2 Restaurante

Disciplina: CMP2304 - Tecnologia de Construção de Software I.

## Enunciado da questão

**QUESTÃO ÚNICA – API REST EM NODE.JS (10,0 pontos)**

Desenvolva uma API REST para o tema “Restaurante”. O recurso principal será prato, contendo os campos id, nome, categoria, preco.

A solução deverá utilizar o conteúdo trabalhado em aula: Node.js, Express, nodemon, morgan, body-parser, CORS, módulo mysql e MariaDB/MySQL. Crie a estrutura do projeto com server.js, app.js, arquivo de configuração/conexão com o banco e arquivo de rotas.

Implemente o CRUD completo: GET /prato, GET /prato/:id, POST /prato, PUT /prato/:id e DELETE /prato/:id. Nas operações de banco, utilize parâmetros/binding na SQL, trate erros de conexão/execução e envie respostas JSON coerentes. Inclua no repositório o script SQL de criação do banco/tabela e deixe o projeto pronto para execução com npm start.
